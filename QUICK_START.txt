 🔥 COMMON ISSUES & FIXES
═══════════════════════════════════════════════════════════════════════

❌ "php: command not found"
   → Download & install PHP from https://www.php.net/downloads
   → After install: php -v (should show version)


❌ "npm: command not found"
   → Download & install Node.js from https://nodejs.org
   → Choose LTS version
   → After install: npm -v (should show version)


❌ "Port 8000 already in use"
   → Use different port: php artisan serve --port 8001
   → Then access: http://localhost:8001


❌ "Port 5173 already in use"
   → npm run dev -- --port 5174


❌ Blank page / 404 error
   → Wait 30 seconds for Vite to compile first time
   → Hard refresh: Ctrl+F5
   → Check console (F12) for errors


❌ Old version of page showing
   → Hard refresh: Ctrl+Shift+F5
   → Clear cache: Ctrl+Shift+Delete


❌ "Cannot find module '@inertiajs/vue3'"
   → npm install


❌ "SQLSTATE: HY000"
   → Run: php artisan migrate
